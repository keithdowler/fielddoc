# App Store Screenshot Plan

## Goal

Show that FieldDoc is serious, field-ready software for documenting job proof and generating customer-ready packets.

## Screenshot Set

1. Home
   - Caption: "Know the next step on every job."
   - Show: Continue Job, attention queue, unsynced item status.

2. Create Job
   - Caption: "Start a job in seconds."
   - Show: job name required, optional customer/site details tucked behind the secondary control.

3. Capture
   - Caption: "Capture Before, Work, and After proof."
   - Show: stage buttons, quick captions, Take Before Photo primary action.

4. Evidence Detail
   - Caption: "Preserve originals and proof metadata."
   - Show: SHA summary, document security summary, annotations.

5. Report Readiness
   - Caption: "See what is missing before delivery."
   - Show: readiness checklist, missing captions, document review.

6. Proof Packet
   - Caption: "Generate a professional Proof Packet."
   - Show: local PDF generated, open/share controls, branded packet preview if available.

7. Cloud Backup
   - Caption: "Back up when the job is ready."
   - Show: subscription active, Back Up Now, upload details.

## Device Guidance

- Use light mode and dark mode captures.
- Use realistic job names, not "test" or "demo."
- Avoid screenshots with developer warnings, simulator overlays, or secret values.
- Use a complete example job with at least one Before, Work, After, and Document item.
